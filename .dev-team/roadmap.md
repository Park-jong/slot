## M0 기획 확정 — 완료

**목표**: 프로토타입을 만들 수 있을 만큼 규칙과 수치 초안을 확정한다.

- [x] 핵심 규칙 정리: 3×3, 8라인, 3칸 일치, 등급 합, 중복 강화, 고정 패턴 적, 릴 편집
- [x] 시작 릴 구성 확률 시뮬레이션 (기획서 8장)
- [→M1] 동작별 계수와 중복 단계 수치 검토 (M1 기획 작업으로 이관)
- [→M1] 첫 캐릭터 스킬과 적 4종 수치 검토 (M1 기획 작업으로 이관)
- [x] 엔진·플랫폼 결정: 웹(TypeScript)
- [x] 릴 편집 빈도 구조 정리: 추가는 매 스테이지(건너뛰기 가능), 삭제·강화는 빈도 설계 대상 (기획서 7장)

**완료 기준**: 기획서 v1.0

## M1 코어 전투 프로토타입 — 진행

**목표**: 전투 1회가 처음부터 끝까지 돌아간다. 그래픽은 임시 도형과 텍스트.

- [x] 기획: M1 데이터 명세 확정 (`docs/specs/m1-combat-spec.md`, 기획서 v0.3)
- [x] 기술 기반: Vite + TypeScript + Vitest, 렌더링은 DOM (게임 프레임워크 없음)
- [x] 릴 데이터와 스핀 (릴별 심볼 목록, 중복 없이 3개 뽑기)
- [x] 8라인 판정, 등급 합, 같은 동작 중복 강화 (단계 효과는 '방어도 무시'만, 나머지는 M3)
- [x] 실행 순서 (방어 → 스킬 → 공격), 방어도, 피해 처리
- [x] 캐릭터 1명(견습 기사)과 고정 패턴 적 2종(슬라임, 고블린), 의도 표시
- [x] 승리·패배 처리
- [x] 판정 로직 단위 테스트 (72개, 난수 주입)
- [x] 확률 시뮬레이터 1차 (`tools/sim/`, 밸런스 회귀 테스트 `npm run test:balance`)
- [x] QA 승인 (1회 수정 후)
- [ ] 사용자 플레이 확인
- [x] REQ-001 명세를 구현에 맞게 갱신 (기획, P1) — 명세 v1.1, 기획서 v0.4

**완료 기준**: 슬라임 상대로 전투를 끝까지 진행할 수 있고, 판정 테스트가 통과한다. → 충족

**M1에서 나온 M2 검토 사항**
- 방패 강타(스킬)가 턴의 약 2%에서만 발동해 사실상 보이지 않음 → 스킬 심볼 비율이나 스킬 설계 재검토
- 전투 사이 HP가 이어지는지 결정 → 고블린 수치 재조정에 영향
- 오우거 '힘 모으기' 처리 방식

## M2 릴 편집 루프와 한 판 완성 — 예정

**목표**: 전투 → 릴 편집 → 다음 전투를 반복해 보스까지 한 판을 끝낼 수 있다.

- 매 스테이지 심볼 추가 (3개 중 1개, 건너뛰기 가능)
- 삭제·강화 기회 (빈도는 아래 결정에 따라)
- 릴 편집 화면 (릴별 구성, 편집 전후 확률 변화 표시)
- 연속 전투 5회 + 보스(오우거)
- 적 4종 전부 구현
- **결정할 것**
  - 런 구조 (기획서 미결 2)
  - 삭제 빈도 (미결 2-1, 잠정 권장: 고정 주기 + 엘리트·이벤트 혼합)
  - 강화 빈도, 삭제와 택1 여부 (미결 2-2)
  - 추가 건너뛰기 보상 (미결 2-3)
  - 캐릭터·파티 방향 (미결 3)
- 시뮬레이터 2차: 기대 피해, 전투 승률, 스테이지별 빈 턴 곡선 (삭제 빈도 결정용)

**완료 기준**: 한 판을 처음부터 보스 처치(또는 패배)까지 진행할 수 있다.

## M3 심볼 조작과 전투 확장 — 예정

**목표**: 빈 턴을 플레이어 선택으로 풀 수 있게 하고, 전투의 깊이를 늘린다.

- 심볼 조작 방식과 사용 제한 결정 후 구현 (기획서 6장)
- 상태 효과: 약화, 기절, 힘 모으기 등
- 추가 동작 검토: 회복, 와일드
- 릴을 건드리는 적 (저주 심볼 투입 등)
- 스킬 단계별 추가 효과 정리

**완료 기준**: 조작 기능이 들어간 상태에서 한 판 플레이테스트, 빈 턴 체감 개선 확인

## M4 콘텐츠 확장과 밸런싱 — 예정

- 캐릭터 2~3명 (고유 스킬과 시작 릴)
- 적 10종 이상, 엘리트, 보스 3종
- 엘리트·보스 보상 차별화
- 메타 성장 여부 결정, 아트 스타일 결정
- 시뮬레이터 기반 밸런스 조정

## M5 연출·사운드·폴리싱 — 예정

- 스핀, 라인 성립, 중복 강화 연출
- 효과음과 배경음
- UI 정리, 튜토리얼
