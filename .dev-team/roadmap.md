## M1 코어 전투 프로토타입 — 완료

**목표**: 전투 1회가 처음부터 끝까지 돌아간다. 그래픽은 임시 도형과 텍스트.

- [x] 기획: M1 데이터 명세 확정 (`docs/specs/m1-combat-spec.md`, 기획서 v0.3)
- [x] 기술 기반: Vite + TypeScript + Vitest, 렌더링은 DOM (게임 프레임워크 없음)
- [x] 릴 데이터와 스핀 (릴별 심볼 목록, 중복 없이 3개 뽑기)
- [x] 8라인 판정, 등급 합, 같은 동작 중복 강화 (단계 효과는 '방어도 무시'만, 나머지는 M3)
- [x] 실행 순서 (방어 → 스킬 → 공격), 방어도, 피해 처리
- [x] 캐릭터 1명(견습 기사)과 고정 패턴 적 2종(슬라임, 고블린), 의도 표시
- [x] 승리·패배 처리
- [x] 판정 로직 단위 테스트 (72개, 난수 주입)
- [x] 확률 시뮬레이터 1차 (`tools/sim/`, 밸런스 회귀 테스트 `npm run test:balance`)
- [x] QA 승인 (1회 수정 후)
- [x] 사용자 확인: M2 진행 지시 (2026-11-17). 플레이 소감은 받는 대로 M2에 반영
- [x] REQ-001 명세를 구현에 맞게 갱신 (기획, P1) — 명세 v1.1, 기획서 v0.4

**완료 기준**: 슬라임 상대로 전투를 끝까지 진행할 수 있고, 판정 테스트가 통과한다. → 충족

**M1에서 나온 M2 검토 사항**
- 방패 강타(스킬)가 턴의 약 2%에서만 발동해 사실상 보이지 않음 → 스킬 심볼 비율이나 스킬 설계 재검토
- 전투 사이 HP가 이어지는지 결정 → 고블린 수치 재조정에 영향
- 오우거 '힘 모으기' 처리 방식

## M2 릴 편집 루프와 한 판 완성 — 진행

**목표**: 전투 → 릴 편집 → 다음 전투를 반복해 보스까지 한 판을 끝낼 수 있다.

**잠정 결정** (2026-11-17, 사용자 미확정 — 디렉터 추천안으로 진행, 사용자가 바꾸면 따름)
- 런 구조: 일직선 연속 전투 5회 + 보스(오우거). 갈림길 지도는 M4
- 삭제·강화: 고정 주기마다 "삭제 또는 강화" 중 하나를 고르는 기회. 주기는 기획 팀이 시뮬레이션으로 결정
- 추가 건너뛰기 보상: 없음 (플레이 후 재검토)
- 전투 사이 HP: 이어짐. 회복 수단 여부와 양은 기획 팀이 밸런스로 결정
- 캐릭터: 견습 기사 1명 유지. 파티는 M4에서 검토
- 스킬 발동률: "3칸 일치" 규칙은 유지(예외 없음). 시작 릴 비율이나 보상 구성으로 해결

**할 일**
- [x] 기획: M2 명세 (보상 심볼 목록·등급 확률, 삭제·강화 주기, HP 이어짐·회복, 적 4종 수치, 오우거 '힘 모으기', 스테이지 구성, 스킬 발동률 대책)
- [x] 기획: REQ-002 같은 효과 중복 규칙
- [x] 기획: 시뮬레이터 2차 (스테이지별 빈 턴 곡선, 한 판 승률)
- [x] 개발: 런 진행, 보상(심볼 추가) 화면, 삭제·강화 화면 (편집 전후 확률 표시)
- [x] 개발: 해골 병사, 오우거 구현
- [x] 개발: REQ-003 M1 코드 정리 (시드 표시 숨기기 포함)
- [x] QA: 테스트와 리뷰, `npm run test:balance` — 1회 수정 후 승인. 실제 엔진 20만 판 = 기획 시뮬레이터와 일치 (승률 59.04%, 보스전 빈 턴 14.67%)
- [ ] 사용자 플레이 확인
- [ ] REQ-005 M2 명세 수치 주석·API 반영, 보스전 빈 턴 목표 결정 (기획, P1)

**완료 기준**: 한 판을 처음부터 보스 처치(또는 패배)까지 진행할 수 있다. → 충족

**M2에서 나온 검토 사항 (플레이 후 판단)**
- 시작 릴의 방어 발동률이 2.3%로 낮아 방어 심볼이 거의 쓸모없음 (스킬과 비율을 맞바꾼 결과)
- 삭제·강화 기회가 한 판에 1회뿐이라 적다는 의견 (2회면 승률 74.5%, 재조정 필요)
- 아무거나 받는 플레이의 승률 4.7% — 최소 여유를 둘지
- 보스전 빈 턴 14.5~14.9% (목표 15~20%)

## M3 심볼 조작과 전투 확장 — 예정

**목표**: 빈 턴을 플레이어 선택으로 풀 수 있게 하고, 전투의 깊이를 늘린다.

- 심볼 조작 방식과 사용 제한 결정 후 구현 (기획서 6장)
- 상태 효과: 약화, 기절, 힘 모으기 등
- 추가 동작 검토: 회복, 와일드
- 릴을 건드리는 적 (저주 심볼 투입 등)
- 스킬 단계별 추가 효과 정리

**완료 기준**: 조작 기능이 들어간 상태에서 한 판 플레이테스트, 빈 턴 체감 개선 확인

## M4 콘텐츠 확장과 밸런싱 — 예정

- 캐릭터 2~3명 (고유 스킬과 시작 릴)
- 적 10종 이상, 엘리트, 보스 3종
- 엘리트·보스 보상 차별화
- 메타 성장 여부 결정, 아트 스타일 결정
- 시뮬레이터 기반 밸런스 조정

## M5 연출·사운드·폴리싱 — 예정

- 스핀, 라인 성립, 중복 강화 연출
- 효과음과 배경음
- UI 정리, 튜토리얼
