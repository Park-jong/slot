- 참여 팀원: 밸런스 디자이너 (시뮬레이터·수치·근거 표), 시스템 디자이너 (명세·GDD v0.6). 팀장은 REQ-005 1·3부 문서 수정과 `ms-config.mjs`/`ms-engine.mjs` 초안을 직접 작성했으나(가드 훅이 이후 직접 작성을 막음) 밸런스 디자이너가 검토·재작성함. 이 직접 작성은 원칙(산출물은 팀원이)에서 벗어난 것이라 기록해 둔다
- 산출물: `docs/specs/m25-multispin-spec.md`, `docs/game-design.md` (v0.6), `docs/specs/m2-run-spec.md` (REQ-005 주석), `tools/sim/ms-config.mjs`, `ms-engine.mjs`, `ms-sim.mjs`, `ms-sweep.mjs`, `ms-turn-stats.mjs`, `ms-reel-stats.mjs`, `ms-examples.mjs`
- 결정 사항: 스핀 1회 필수 후 매번 계속/멈춤 선택, 턴당 정산 1회. 합산 = 라인 풀링(B1) + 단계표 상한 x1/1.5/2, 방어도 무시 3줄 (M2 단계표로 풀링하면 1→3스핀 4.35배로 항상 최대 스핀이 지배). 남은 스핀 이득 = Focus 1회당 +50% (방어 변환·저장·M3 토큰 기각, 위험 요소 없음). 스핀 수 = 기본값 + 수정치(add/mulPct, 1~5 클램프), damagePct·focusPctAdd 훅. 시작 릴 AAAGGSS (다중 스핀으로 방어 발동이 자연 해결되지 않음: 6.8%/턴). 적 HP 약 3배(슬라임 72 ... 오우거 310). 승률 smart 61.8% / 항상 최대 45.8% / 항상 1회 0.1% / takeall 5.6% / none 0.1%. 보스 빈 턴 목표: 한 턴 전체 1~4% + 빈 스핀 25~35% (REQ-005 2부)
