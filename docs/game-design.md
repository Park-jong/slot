## 2. 슬롯판

### 2.1 구조

- **3×3 격자**: 세로 줄 3개(= 릴 3개) × 가로 3칸.
- **릴마다 심볼 구성이 다르다.** 각 릴은 자기만의 심볼 목록을 가진다. 같은 심볼이 여러 개 들어갈 수 있고, 들어 있는 개수가 곧 확률이다.
- 릴 크기: **최소 3개**(스핀 1회에 3칸을 채워야 하므로), **최대 12개**(잠정).

### 2.2 스핀 규칙

- 각 릴은 자기 심볼 목록에서 **중복 없이 3개를 뽑아** 위에서 아래로 배치한다. 카드 덱에서 3장 뽑는 것과 같다.
- 따라서 어떤 심볼이 특정 칸에 나올 확률 = (그 릴에 있는 그 심볼 수) ÷ (그 릴의 전체 심볼 수).
- 연출은 일반 슬롯처럼 릴이 돌다가 왼쪽부터 차례로 멈춘다(판정 로직과 무관).

### 2.3 라인 (총 8줄)

```
 칸 번호            라인
 ┌───┬───┬───┐      가로 H1: 1-2-3   세로 V1: 1-4-7   대각 D1(↘): 1-5-9
 │ 1 │ 2 │ 3 │           H2: 4-5-6        V2: 2-5-8        D2(↗): 7-5-3
 ├───┼───┼───┤           H3: 7-8-9        V3: 3-6-9
 │ 4 │ 5 │ 6 │
 ├───┼───┼───┤      ※ 세로 V1~V3는 각각 릴 1~3 하나에 해당한다.
 │ 7 │ 8 │ 9 │        세로 라인은 한 릴에 같은 동작을 몰아넣는 빌드로 노리게 된다.
 └───┴───┴───┘
```

- **성립 조건: 한 줄의 3칸이 모두 같은 동작일 때만** 성립한다. 2칸 일치는 아무 효과가 없다.
- 등급은 일치 조건에 포함되지 않는다. 동작만 같으면 등급이 달라도 성립한다.
- 한 칸이 여러 라인에 동시에 포함될 수 있다. 가운데 칸(5)은 4개 라인(H2, V2, D1, D2)에 걸려 가장 가치가 높다. **이 불균형은 의도한 것으로 유지한다.**
- 성립한 라인이 하나도 없으면 그 턴에는 아무 행동도 하지 않는다. (→ 이를 보완하는 수단은 6장 심볼 조작)

## 3. 심볼

### 3.1 심볼 = 동작 + 등급

각 심볼은 **동작** 하나와 **등급** 하나를 가진다. 예: `공격(희귀)`, `방어(일반)`.

### 3.2 동작 종류 (M1 기준)

| 동작 | 아이콘(임시) | 효과 | 기본 계수 |
|---|---|---|---|
| 공격 | ⚔ | 적에게 피해 | 등급 1당 피해 2 |
| 방어 | 🛡 | 이번 턴 적 공격을 막는 방어도 획득 | 등급 1당 방어도 2 |
| 스킬 | ✦ | 캐릭터 고유 스킬 발동 (4장) | 스킬마다 다름 |

- 서로 다른 스킬은 **서로 다른 동작**으로 취급한다. 예를 들어 `화염` 심볼과 `치유` 심볼은 한 줄을 이루지 못한다.
- ⚠ **밸런스 주의**: 동작 종류가 늘수록 같은 동작 3개가 한 줄에 모일 확률이 급격히 떨어진다(8장 시뮬레이션 참고). 캐릭터 1명이 가진 스킬 종류는 **1~2개**로 제한하는 것을 권장한다.

### 3.3 등급

| 등급 | 등급 값 | 색(임시) |
|---|---|---|
| 일반 | 1 | 회색 |
| 고급 | 2 | 초록 |
| 희귀 | 3 | 파랑 |
| 영웅 | 4 | 보라 |

- 라인의 세기는 그 줄 3칸의 **등급 값 합**(3~12)으로 정한다.

## 4. 행동 계산

### 4.1 라인 1개의 위력

```
라인 위력 = 동작 기본 계수 × 라인 등급 합
```

예: `공격(일반) · 공격(희귀) · 공격(일반)` → 등급 합 1+3+1 = 5 → 피해 2 × 5 = **10**

### 4.2 같은 동작 중복 → 강화

한 턴에 같은 동작 라인이 여러 개 성립하면, 따로따로 쓰지 않고 **하나의 더 강한 동작**으로 합쳐서 쓴다.

```
최종 위력 = (해당 동작 라인들의 위력 합) × 중복 배율
```

| 같은 동작 라인 수 | 단계 | 중복 배율 | 공격 추가 효과 | 방어 추가 효과 |
|---|---|---|---|---|
| 1 | 기본 | ×1.0 | – | – |
| 2 | 강화 | ×1.5 | 방어도 무시 | 받은 피해 일부 반사(30%) |
| 3 | 상급 | ×2.0 | 방어도 무시 + 약화 부여 | 반사 50% |
| 4 이상 | 궁극 | ×3.0 | 위 효과 + 연속 2회 타격 | 다음 턴까지 방어도 유지 |

- **M1 구현 범위**: 추가 효과는 공격의 "방어도 무시"(2라인 이상)만 구현한다. 약화, 연속 타격, 반사, 방어도 유지, 방패 강타의 기절은 **M3로 보류**하며 M1에서는 배율만 적용한다. 방어도 무시는 적 방어도를 소모하지 않는다. (상세: [`m1-combat-spec.md`](specs/m1-combat-spec.md))
- 스킬의 단계별 추가 효과는 스킬마다 따로 정의한다.
- 수치는 모두 잠정이며 M1 플레이테스트 후 조정한다.

**계산 예시**: 공격 라인 2개(등급 합 5, 4) + 방어 라인 1개(등급 합 3)
- 공격: (2×5 + 2×4) × 1.5 = **27 피해, 방어도 무시**
- 방어: 2 × 3 = **방어도 6**

### 4.3 실행 순서

한 턴에 여러 동작이 성립하면 **방어 → 스킬 → 공격** 순으로 실행한다. 버프형 스킬이 같은 턴 공격에 적용되도록 하기 위해서다.

## 5. 전투

### 5.1 캐릭터

- M1은 **캐릭터 1명**으로 진행한다. (파티 여부는 9장 미결 사항)
- 캐릭터가 정하는 것: 최대 HP, 고유 스킬 1~2종, 시작 릴 구성.
- 첫 캐릭터(임시) — **견습 기사**
  - HP 50
  - 스킬 `방패 강타`: 등급 1당 피해 1 + 방어도 1. 강화(2라인) 이상이면 적 기절(다음 행동 1회 취소) 효과를 **M3에 구현 예정**이며, M1은 배율만 적용한다.
  - 시작 릴: 8.2절 권장안

### 5.2 적 — 고정 패턴

- 적은 정해진 **행동 패턴을 순서대로 반복**한다.
- 적의 **다음 행동(의도)은 항상 화면에 표시**된다. 플레이어는 이를 보고 "이번엔 방어가 터져야 한다"를 기대하며 스핀하고, 나중에는 심볼 조작(6장)으로 대응한다.

| 적(임시) | HP | 패턴 |
|---|---|---|
| 슬라임 | 24 | 공격 5 → 공격 5 → 방어 5 |
| 고블린 | 34 | 공격 5 → 공격 9 → 공격 5 |
| 해골 병사 | 40 | 방어 6 → 공격 10 |
| 보스: 오우거 | 90 | 공격 8 → 힘 모으기(다음 공격 2배) → 공격 16 → 방어 10 |

- 이후 확장: 플레이어 릴에 `저주` 심볼(어떤 라인도 이루지 못함)을 섞는 적 등, 릴 시스템을 건드리는 적.

### 5.3 턴 흐름

1. **턴 시작**: 플레이어 방어도 0으로 초기화, 적 의도 표시
2. **스핀**
3. **(심볼 조작 — 6장, M3에서 추가)**
4. **라인 판정**: 8줄 검사 → 동작별로 묶기 → 중복 단계 결정
5. **행동 실행**: 방어 → 스킬 → 공격
6. 적 HP 0이면 승리
7. **적 행동**: 의도대로 실행 (공격은 플레이어 방어도에서 먼저 차감)
8. 플레이어 HP 0이면 패배, 아니면 1로

## 6. 심볼 조작 (M3 예정)

라인이 하나도 안 나오는 턴의 답답함을 플레이어 선택으로 풀어 주는 장치. **스핀 후, 판정 전**에 한 번 쓴다.

- 기본안: 격자의 **심볼 1개를 조작**할 수 있다. 구체적인 방식은 M3에서 아래 후보 중 결정한다.
  - 인접한 두 칸 맞바꾸기
  - 릴 하나를 한 칸 위/아래로 밀기
  - 칸 하나만 다시 뽑기
- 사용 제한(쿨다운, 자원, 횟수) 방식도 M3에서 결정한다.
- 조작을 고려해, M1부터 판정 로직은 "스핀 결과 격자 → 판정"으로 분리해 둔다. 조작은 그 사이에 격자를 바꾸는 단계로 끼워 넣는다.

## 7. 릴 편집

릴 편집은 **추가·삭제·강화**로 이루어진다. 세 가지는 성장에 미치는 힘이 다르므로 **얻을 수 있는 빈도를 따로 설계한다.**

| 편집 | 내용 | 제약 | 빈도 |
|---|---|---|---|
| 심볼 추가 | 무작위 심볼 3개 중 1개를 골라 원하는 릴에 넣는다 | 릴 최대 12개 | **매 스테이지 클리어 시 (건너뛸 수 있음)** |
| 심볼 삭제 | 원하는 릴에서 심볼 1개를 뺀다 | 릴 최소 3개 | **제한적: 7.3에서 설계** |
| 심볼 강화 | 심볼 1개의 등급을 한 단계 올린다 | 최대 영웅 | 제한적: 7.4에서 설계 |

### 7.1 공통 원칙

- 같은 심볼이라도 **어느 릴에 넣고 어느 릴에서 빼느냐**가 전략이 된다.
  - 가운데 릴(릴 2)은 가운데 칸을 거치는 가로·대각선 라인에 기여한다.
  - 한 릴을 한 동작으로 채우면 세로 라인이 확정에 가까워진다.
- 편집 화면에는 릴별 구성과 **편집 후 동작별 발동 확률 변화**를 미리 보여 준다(시뮬레이터 결과 활용).

### 7.2 심볼 추가 — 매 스테이지 (건너뛰기 가능)

- 스테이지를 클리어할 때마다 무작위 심볼 3개가 제시되고, 1개를 골라 원하는 릴에 넣거나 **건너뛴다**.
- 추가는 그 동작의 비율을 올리지만 **다른 동작을 묽게 만든다.** 원하지 않는 심볼이면 건너뛰는 게 정답일 수 있어야 한다.
- 건너뛰기에 작은 보상을 줄지 검토한다. 예: 골드 소량, 삭제 게이지 +1(7.3 C안과 연결).
- 엘리트·보스 보상은 선택지 수 증가, 높은 등급 심볼 등장 등으로 차별화한다(M4).

### 7.3 심볼 삭제 — 빈도 설계 (M2에서 결정)

**왜 따로 설계하나**: 삭제는 추가보다 훨씬 강하다. 원하는 동작이 늘어나는 동시에 나머지가 묽어지지 않기 때문이다.

시작 릴(릴마다 공격3·방어2·스킬1) 기준 시뮬레이션:

| 편집 | 빈 턴 확률 | 공격 발동 | 2라인 이상 공격 |
|---|---|---|---|
| 시작 상태 | 33.0% | 52.5% | 17.4% |
| 공격 추가 1회 (릴 1개) | 29.8% (−3.2%p) | 57.9% | 22.7% |
| 스킬 삭제 1회 (릴 1개) | 25.8% (−7.2%p) | 60.0% | 23.2% |
| 공격 추가 3회 (릴마다 1회) | 23.2% | 68.3% | 34.1% |
| 스킬 삭제 3회 (릴마다 1회) | **9.6%** | 74.9% | 37.5% |

- **삭제 1회의 효과는 추가 1회의 약 2배**이고, 3회만 몰아도 빈 턴이 10% 아래로 떨어진다.
- 그래서 삭제를 매 스테이지 주면 릴이 금방 "압축"되어 운의 긴장감이 사라진다. 너무 안 주면 추가만 쌓여 릴이 묽어지고 원하는 빌드를 만들 수 없다.

**후보안**

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A. 고정 주기 | N 스테이지마다 1회 (예: 3 스테이지마다) | 예측 가능, 계획 세우기 쉬움 | 단조로움 |
| B. 특정 노드·이벤트 | 엘리트·보스 처치, 휴식처, 무작위 이벤트에서만 | 런마다 변화, 지도 선택과 연결 | 운에 따라 삭제가 아예 없을 수 있음 |
| C. 게이지 | 스테이지 클리어나 추가 건너뛰기마다 게이지가 차고, 가득 차면 1회 | 플레이어 선택(건너뛰기)이 삭제로 이어짐 | 시스템이 하나 더 늘어남 |
| D. 자원 소비 | 상점에서 골드로 구매, 갈수록 비싸짐 | 다른 보상과 교환하는 결정이 생김 | 상점·재화 시스템 필요 |

**설계 기준**
- 목표 곡선을 먼저 정하고 빈도를 맞춘다. 예: "보스 직전 잘 짠 릴의 빈 턴 15~20%, 그냥 다 받은 릴은 30% 이상".
- 추가 횟수(스테이지 수) 대비 삭제 비율로 조절한다. 예: 추가 3회당 삭제 1회.
- 런 구조(9장 미결 2)와 함께 정한다. 지도에 갈림길이 있으면 B안의 효과가 커진다.

**잠정 권장**: **A + B 혼합**. 일정 주기마다 기본 삭제 1회로 최소한을 보장하고, 엘리트·이벤트로 추가 기회를 준다. M2에서 시뮬레이터로 목표 곡선에 맞춰 확정한다.

### 7.4 심볼 강화 — 빈도 설계 (M2에서 결정)

- 강화는 확률은 그대로 두고 **위력만** 올린다. 삭제보다는 약하지만, 가운데 릴의 핵심 심볼에 몰아 주면 강력하다.
- 삭제와 같은 틀(주기, 노드, 게이지, 자원)로 빈도를 정하되 **삭제와 같은 기회에서 둘 중 하나를 고르게** 하는 방안도 검토한다(확률을 올릴지 위력을 올릴지 선택).

## 8. 확률과 밸런스 기초

### 8.1 시작 릴 구성별 시뮬레이션 (각 20만 회)

릴 3개 모두 같은 구성일 때 (A=공격, G=방어, S=스킬):

| 안 | 릴 1개 구성 | 라인 0개 확률 | 턴당 평균 라인 | 공격 발동 | 방어 발동 | 스킬 발동 |
|---|---|---|---|---|---|---|
| 균등 | AAGGSS | 51.8% | 0.55 | 17.4% | 17.4% | 17.4% |
| 9칸 | AAAAGGGSS | 39.1% | 0.86 | 40.8% | 18.9% | 5.4% |
| **권장** | **AAAGGS** | **33.0%** | **0.98** | **52.3%** | **17.5%** | **2.3%** |
| 압축 | AAAGS | 20.5% | 1.46 | 74.9% | 4.0% | 4.0% |

**알게 된 점**
- "3개 모두 일치" 규칙에서는 **비율이 낮은 동작이 거의 발동하지 않는다.** 릴당 1/6인 스킬은 발동 확률이 2%대다.
- 동작을 고르게 섞으면 절반 이상의 턴이 빈 턴이 된다.
- 그래서 시작 릴은 **공격 위주로 하고 나머지는 적게** 두어 빈 턴을 1/3 정도로 맞추고, 릴 편집으로 다른 동작의 비율을 키워 가는 구조가 맞다.
- 스킬은 발동이 드문 만큼 **한 번 터지면 강하게** 설계한다.

### 8.2 시작 릴 권장안

- 릴 1·2·3 모두 `공격×3, 방어×2, 스킬×1` (전부 일반 등급)
- 첫 전투 기대치: 공격은 두 턴에 한 번 정도, 방어는 다섯 턴에 한 번 정도 발동.

### 8.3 밸런스 도구

- 릴 구성을 넣으면 라인 확률, 동작별 발동 확률, 기대 피해를 계산하는 **시뮬레이터**를 M1~M2에 만든다. 릴 편집 선택지와 적 수치를 맞출 때 기준으로 쓴다.
- M2에서는 "추가 N회 + 삭제 M회"를 거친 릴을 자동으로 만들어 스테이지별 빈 턴 곡선을 그려 보고, 삭제·강화 빈도(7.3, 7.4)를 정하는 데 쓴다.

## 10. 개발 참고 — 데이터 구조 초안

규칙은 데이터로 정의하고, 새 동작·적은 코드 수정 없이 데이터로 추가할 수 있게 한다.

```
Symbol   { actionId, grade }                  // 예: { "attack", 3 }
Reel     { symbols: Symbol[] }                // 3~12개
Board    { cells: Symbol[3][3] }              // 스핀 결과 [릴][행]
Line     { id, cells: [릴,행][3] }            // 8개 고정
Action   { id, name, basePower, tiers: { lineCount, multiplier, effects[] }[] }
Enemy    { id, hp, pattern: Intent[] }
Intent   { type: attack | guard | buff | ..., value }
```

- 스핀(난수) → 조작(M3) → 판정 → 실행을 단계별로 분리한다.
- 난수 생성기는 주입받게 해서 시뮬레이터와 테스트에서 같은 결과를 재현할 수 있게 한다.
